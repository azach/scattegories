A party game · no app, no server, one link

THE LETTER ROUND

Twelve categories. One letter. Three minutes. Share one room link — everyone plays the same board on a synced clock, then sees each other's answers when time's up. Peer-to-peer, no server.

Tip: everyone opens the same room link and lands in the lobby. The host starts the round; the letter is revealed to all at once and the 3:00 begins together.
1
Open a room

Start a game and send the room link to your friends — anywhere in the world. It stays the same all night.

2
Beat the clock

The host starts the round. Fill an answer for each category that begins with the chosen letter before 3:00 runs out.

3
Compare & score

At time-up everyone's answers appear side by side, duplicates flagged. Tick the ones only you got — 1 point each.
