THE LETTER ROUND

Twelve categories. One letter. Three minutes. Share the link — everyone gets the exact same board and a synced countdown, straight from a static web page.

Tip: everyone opening the same link plays the same round. Pressing Start opens a 30-second window to share the link — then the letter is revealed to everyone at once and the 3:00 begins.
